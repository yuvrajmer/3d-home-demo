# Oak Hill House – React scroll tour

1. Install Node.js (v18+)
2. In this folder run:
   npm install
   npm run dev
3. Open the local link shown in the terminal.

Main page = video 1+2 (scroll). Click the + on the door at the top to open the bedroom (video 3, also scroll-driven).
Edit text, room names and scroll timings in src/App.jsx (ROOMS array).
Replace the videos in public/videos/ (1.mp4, 2.mp4, 3.mp4) with your own.
Build for hosting: npm run build  (output in /dist)
